# Data Sources & Attribution

| Dataset | Provider | Role in this project | Real / Simulated | Usage notes |
|---|---|---|---|---|
| SECOM | UCI Machine Learning Repository (semiconductor manufacturing data) | SPC, early warning, yield trend, feature RCA | Real, historical | Raw files gitignored and never redistributed; cite the UCI SECOM dataset when reusing results. |
| MetroPT-3 | UCI Machine Learning Repository, DOI `10.24432/C5VW3R`, **CC-BY-4.0** | Industrial sensor / failure-window analysis at scale | Real sensor data; failure windows are documented intervals transcribed from the dataset description, not observed labels | Raw files gitignored; CC-BY-4.0 requires attribution — this file and `docs/data_setup.md` provide it. |
| MES (work orders, downtime, shifts, manpower, scrap) | Generated by `src/simulate_mes.py` (this repository) | OEE, Pareto, RCA, work orders, capacity, Power BI model | **Simulated**, seed 42, openly injected scenarios | Committed processed CSVs are project-generated and freely reusable. |
