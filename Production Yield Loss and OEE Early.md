Production Yield Loss and OEE Early-Warning System
Item	Detail
Problem	Yield drops and line bottlenecks are found days late in manual Excel reports, so scrap and missed deliveries pile up
Target users	Production supervisors, process and quality engineers, planning
Industries	Semiconductor, E&E, medical devices, manufacturing, food processing
Data	UCI SECOM (semiconductor sensor and pass/fail data); Kaggle Bosch Production Line Performance; simulated MES work orders, downtime, and shift logs
Stack	PostgreSQL, Python (pandas, scipy), Power BI with DAX, Excel

Core features

OEE breakdown by line and shift: Availability × Performance × Quality
SPC control charts with Western Electric rule alerts
Pareto chart of top defect and downtime causes
Work-order status tracking against plan
Capacity and manpower view

Skills shown

SQL
Star-schema modeling
Statistics (SPC, correlation)
KPI design
Root-cause analysis
Anomaly detection
Excel-to-dashboard migration

Measurable impact

Hours from defect occurrence to alert
% of scrap cost explained by the top 3 causes
Reporting time cut from manual to automated

Resume evidence: "Built SQL and Power BI OEE monitoring on X lots; SPC alerts flagged yield excursions Y hours earlier; Pareto isolated 3 causes driving Z% of scrap."
